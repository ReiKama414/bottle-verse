# 3D 瓶中微縮世界 — 海盜船與海洋 (Three.js + WebGL)

以 **Three.js + WebGL + 自訂 GLSL Shaders** 打造的即時互動 3D 瓶中微縮世界（Ship in a Bottle Voxel Diorama），支援光影折射玻璃瓶、動態波浪與浮力物理、日夜晨昏流轉、晴雨暴風雨天氣系統、4 大可切換微縮主題世界，以及火砲齊射、海豚躍水、搖晃瓶身、投擲漂流木桶與點擊海面投石等豐富互動。

## 專案結構

```text
ship-in-a-bottle-3d/
├── index.html                    # 主程式入口（模組化載入）
├── standalone.html               # 單檔獨立可執行版本（內嵌完整程式碼與離線 WebGL 引擎，雙擊即可執行）
├── package.json                  # 專案設定與本地伺服器啟動腳本
├── LICENSE                       # MIT 授權宣告
├── README.md                     # 專案說明文件
├── css/
│   └── style.css                 # 航海羊皮紙與黃銅風格控制面板、響應式手機版介面
└── js/
    ├── three-offline-fallback.js # 內建 WebGL2/WebGL1 Three.js 相容渲染核心（無須外網亦能 100% 離線執行）
    ├── voxel-engine.js           # Voxel 網格編譯器（隱藏面剔除、4 鄰域頂點環境光遮蔽 Voxel AO、倒角法線與 3D 黃銅銘牌字體）
    ├── bottle-and-stand.js       # 橫置玻璃瓶 Lathe 幾何、雙通道玻璃折射/高光 Shader、軟木塞封蠟、麻繩吊牌與木質展示架
    ├── water-and-shaders.js      # 多重 Gerstner 海浪 GLSL Shader、岸際與浪尖像素白沫、互動水波紋、弧形透明水體剖面與海底焦散
    ├── scenes-builder.js         # 4 大瓶中微縮世界生成器（海盜船與燈塔、幽靈船與火山、極光冰海與維京船、東方寶船與櫻花神社）
    ├── atmosphere-and-fx.js      # 日夜天體軌跡、星光與螢火蟲、立體漂浮雲朵、展翅海鷗、暴雨閃電、火砲拋體、海豚躍水與 Web Audio 音效合成
    ├── controls-and-ui.js        # 阻尼 OrbitControls（滑鼠拖曳旋轉、滾輪縮放、手機單指旋轉與雙指縮放、3D 海面點擊投石）
    └── main.js                   # 主渲染迴圈、瓶身搖晃彈簧阻尼物理、浮力姿態解算與 UI 控制綁定
```

## 快速執行方式

1. **直接雙擊開啟**：
   - 解壓縮後直接以瀏覽器開啟 `index.html` 或 `standalone.html` 即可立即體驗（內建離線 WebGL2 渲染核心，即使無網路環境也能完整運行）。
2. **使用本地開發伺服器（選用）**：
   ```bash
   npx serve .
   # 或使用 Python
   python3 -m http.server 8080
   ```
   接著於瀏覽器開啟 `http://localhost:8080`。

## 視覺與互動功能一覽

- **精緻 Voxel 立體像素與環境光遮蔽 (Voxel AO)**：每個島嶼、山脈、珊瑚礁、燈塔與帆船皆經過隱藏面剔除與 4 鄰域頂點 AO 烘焙，搭配微倒角法線與線性空間 ACES 色調映射。
- **雙通道物理玻璃瓶與木質展示架**：重現玻璃瓶頂部縱向高光帶、底部邊緣折射、Fresnel 輪廓光、軟木塞紅封蠟、隨風擺動的像素船錨吊牌，以及隨場景自動更換 3D 立體像素刻字的黃銅銘牌（`MARIGOLD · 1742` 等）。
- **日夜時間滑桿 (`00:00 – 24:00`) 與自動流轉**：太陽與月亮沿瓶內弧線升落，夜晚自動點亮燈塔旋轉光束、守塔人小屋窗光、海盜船尾樓提燈、沙灘營火以及滿瓶星光與螢火蟲。
- **天氣系統（晴天 / 雨天 / 暴風雨）與海浪強度滑桿 (`0% – 100%`)**：即時控制波浪振幅、白沫密度、傾斜雨絲、3D 閃電雷鳴與船隻隨浪俯仰橫搖幅度。
- **4 大可切換瓶中微縮世界**：
  1. **🏴‍☠️ 海盜船與燈塔 (`MARIGOLD · 1742`)**：三桅海盜帆船、紅白條紋燈塔與小屋、雙峰瀑布岩島、熱帶椰林營火寶藏島與五彩珊瑚礁海底。
  2. **👻 幽靈船與火山 (`DUTCHMAN · 1688`)**：翡翠幽冥鬼船、噴發熔岩火山島、骷髏岩堡壘與深海發光珊瑚。
  3. **❄️ 極光與維京船 (`VALKYRIE · 0985`)**：維京龍頭戰船、北歐烽火瞭望塔、晶透冰川峽灣與動態北極光幕。
  4. **🌸 寶船與櫻花島 (`RYUJIN · 1543`)**：東方朱紅寶船、水上赤紅鳥居、三層五重塔、盛開櫻花林與瀑布山嵐。
- **趣味微互動**：開砲射擊 (`Fire cannon`)、召喚海豚躍水 (`Dolphins`)、搖晃玻璃瓶身 (`Rock bottle`)、投擲漂流木桶 (`Toss barrel`)、點擊瓶中海面投下許願石激起漣漪，以及純 Web Audio API 即時合成之海浪與音效。
